# Blockbound

A side-view block platformer with a world you can reshape.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite.

## Controls

- **A/D** or **arrow keys** — Move
- **Space**, **W**, or **Up** — Jump
- **Left click** — Mine a block
- **Right click** — Place a selected block
- **1–4** or mouse wheel — Select a block
- **R** — Reset the level

## Build

```bash
npm run build
```
